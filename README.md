# Mini Code Editor

A lightweight desktop code editor built with **Python** and **PyQt6**.

## Features

* Code editing with multiple tabs
* File explorer
* Syntax highlighting
* Search and replace
* Built-in Python terminal
* SQLite database viewer
* Save and Save As
* Recent files
* Dark and light themes
* Line numbers
* Word wrap
* Auto-save
* Font and tab size customization
* Text encoding selection
* Fullscreen mode
* Editor zoom
* Toggle comments

## Supported Languages

Syntax highlighting is available for:

* Python
* JavaScript
* HTML
* CSS
* C
* C++
* JSON
* Markdown
* SQL
* Bash

## Requirements

* Python 3
* PyQt6

Install PyQt6:

```bash
pip install PyQt6
```

## Run

```bash
python main.py
```
